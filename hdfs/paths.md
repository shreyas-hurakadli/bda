# HDFS Path Layout

The project uses a simple medallion-style layout under `/data/student`.
For local demos, HDFS runs inside the project container and stores its data in
`.runtime/`, not in system-level Hadoop directories.

## Landing

Raw semicolon-delimited CSVs copied from the local dataset:

```text
/data/student/landing/
  student-mat.csv
  student-por.csv
```

These files are the source of truth. Do not edit them in HDFS during demos.

## Curated

Typed Parquet generated by `spark/01_ingest_clean.py`:

```text
/data/student/curated/student_course_performance/
  course_id=MAT/
  course_id=POR/
```

The curated table normalizes column names, casts numeric fields, adds
`student_key`, adds `source_file`, and derives `course_id`.

## Mart

Feature and warning outputs generated by Spark:

```text
/data/student/mart/student_features/
  course_id=MAT/
  course_id=POR/

/data/student/mart/risk_flags/
  course_id=MAT/
  course_id=POR/
```

## Hive

Hive database: `student_warn`

External tables:

- `student_course_performance`
- `student_features`
- `risk_flags`

Views:

- `v_at_risk_students`
- `v_course_risk_summary`
- `v_school_risk_summary`
